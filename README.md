# Микрофон — React + Vite + Decap CMS

Минимальный React-проект без оформления. Цены, новости, галерея и контакты хранятся в `public/content/` и редактируются через `/admin/`.

Логика загрузки данных находится в `src/App.jsx`, а секции — в JSX-компонентах `src/components/`. Стили можно добавить самостоятельно; TypeScript в проекте не используется. В админке можно загрузить несколько фото для каждой новости и управлять фотографиями галереи. Загруженные файлы сохраняются в `public/uploads/` и доступны на сайте по путям `/uploads/…`.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Сайт откроется по адресу `http://127.0.0.1:5173/`. Вместо `npm run dev` можно использовать `npm start`. Если порт 5173 занят другим процессом, остановите его или задайте другой порт: `npm run dev -- --port 5174`.

## Локальная админка

Decap CMS записывает изменения в файлы проекта через локальный прокси. Запустите во втором терминале:

```bash
npm run cms
```

Затем откройте `http://127.0.0.1:5173/admin/`. Локальный прокси работает на порту 8081 и сохраняет файлы прямо в папку проекта. После сохранения обновите страницу сайта, чтобы увидеть изменения. Если прокси не запускается, убедитесь, что порт 8081 свободен.

## Публикация админки

Сайт собирается командой `npm run build`; готовые файлы находятся в `dist/`. Для работы опубликованной админки нужен Git backend и авторизация редакторов. В `public/admin/config.yml` пока указан `git-gateway` для локального сценария Decap. Перед публикацией выберите провайдера, укажите репозиторий и настройте вход. Например, для GitHub требуется OAuth-сервис или Decap Turbo; одного `repo` в конфиге недостаточно. Изменения через CMS будут попадать в Git, после чего хостинг должен пересобрать сайт.

## Где данные

- `public/content/prices.json` — список услуг и цен;
- `public/content/news.json` — новости;
- `public/content/gallery.json` — галерея;
- `public/content/contacts.json` — контакты;
- `public/admin/config.yml` — поля редактора Decap CMS.

Замените демонстрационные цены и контакты на реальные перед публикацией.
